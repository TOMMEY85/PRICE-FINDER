# Extension Chrome / Edge

1. Lance d'abord PRICE FINDER sur Windows.
2. Ouvre Chrome ou Edge et va dans la page des extensions.
3. Active le **mode développeur**.
4. Choisis **Charger l'extension non empaquetée**.
5. Sélectionne le dossier `extension` de ce projet.
6. Sur une page produit, sélectionne le nom/référence de la pièce, clic droit puis **Comparer avec PRICE FINDER**.

L'extension ouvre PRICE FINDER avec la recherche préremplie.
