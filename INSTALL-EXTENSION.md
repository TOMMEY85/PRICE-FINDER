# Extension Chrome / Edge — PRICE FINDER

Cette version ouvre PRICE FINDER dans une **petite fenêtre indépendante du navigateur** et tente automatiquement d'identifier le produit de la page.

## Installation

1. Télécharge ou clone le dépôt PRICE-FINDER.
2. Ouvre Chrome ou Edge.
3. Va dans la page des extensions (`chrome://extensions` ou `edge://extensions`).
4. Active le **Mode développeur**.
5. Clique sur **Charger l'extension non empaquetée**.
6. Sélectionne le dossier `extension` du projet.
7. Épingle **PRICE FINDER** dans la barre du navigateur.
8. Recharge les pages produits déjà ouvertes après l'installation/rechargement de l'extension.

## Utilisation automatique

Sur une fiche produit, par exemple une RTX, un Ryzen, une carte mère, de la RAM, un SSD, une alimentation ou un boîtier :

1. Clique sur l'icône **PRICE FINDER**.
2. Une petite fenêtre d'environ **520 × 720 px** s'ouvre.
3. PRICE FINDER récupère le nom, la marque, le modèle et la référence de la page quand ils sont disponibles.
4. La comparaison est lancée automatiquement sur `https://price-finder.netlify.app`.
5. Les offres matérielles affichées doivent avoir un **prix vérifié sur la fiche produit**.
6. Clique sur **Voir le produit** pour ouvrir directement la fiche du revendeur.

## Autres méthodes

- Sélectionner une référence sur une page → clic droit → **Comparer avec PRICE FINDER**.
- Clic droit sur une page → **Comparer cette page avec PRICE FINDER**.
- Une recherche peut toujours être saisie manuellement dans la petite fenêtre.

L'extension n'essaie pas de contourner les CAPTCHA, connexions ou systèmes anti-bot des revendeurs.
